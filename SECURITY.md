# Security Policy

## Supported Versions


| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

Please email **hello@releasedgroup.com** to report any suspected security vulnerabilities in this repository. To help us investigate and respond efficiently, include, where possible:

- A clear description of the issue and why you believe it is a vulnerability  
- Step-by-step instructions to reproduce the issue  
- Any proof-of-concept code, payloads, or screenshots  
- The component(s), API(s), or area(s) of the project you believe are affected  
- The impact you believe the issue could have (e.g., data exposure, privilege escalation, denial of service)  
- The version(s) of the project and environment details (OS, runtime, browser, etc.)  
- Any relevant logs or error messages (with sensitive data redacted)  

We will aim to acknowledge receipt of your report within **5 business days** and will keep you reasonably informed of the progress of our investigation and remediation efforts. Please avoid publicly disclosing the vulnerability until we have had an opportunity to address it.
